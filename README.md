# Timetable

安卓课表 App，使用个人教务系统账号查询本人课表。Kotlin + Jetpack Compose。

## 功能

- 教务系统账号登录，自动拉取本学期课表
- 数据自动更新：打开时静默刷新，回前台超过 10 分钟自动刷新，任意页面可下拉手动刷新
- 今日页：按周过滤，当前节 / 下一节高亮
- 周课表：网格视图，左右滑动切换周次
- 课程详情弹窗
- 开学日期设置，自动计算当前周次
- 凭据加密存储（Android Keystore），数据仅存本地

## 构建

```bash
gradlew :app:testDebugUnitTest :app:assembleDebug :app:assembleRelease
```

需 Android SDK（`ANDROID_HOME`）。release 包输出于 `app/build/outputs/apk/release/`。
